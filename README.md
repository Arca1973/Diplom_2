Название проекта

# Stellar Burgers Automation Tests

Описание

Этот проект представляет собой дипломную работу, включающую тестирование REST API  с использованием различных инструментов автоматизации тестирования.

Используемые технологии

- Java 11: основной язык программирования.
- JUnit 4.13.2: фреймворк для юнит-тестирования.
- Maven 3.9.0: система сборки проектов.
- RestAssured 5.2.0: библиотека для тестирования REST API.
- Allure 2.15.0: фреймворк для красивого отображения результатов тестов.

Настройка проекта

1. Убедитесь, что у вас установлены:
   - Java 11 или выше.
   - Maven 3.9.0 или выше.
   
2. Клонируйте репозиторий или скачайте архив с проектом.

3. Откройте терминал в корневой директории проекта.

4. Установите зависимости :

Запустите команду для установки всех необходимых зависимостей:
mvn clean install

5. Запуск тестов

Для запуска всех тестов выполните следующую команду:

mvn clean test


Эта команда очистит проект от предыдущих сборок (clean) и запустит тесты (test).

6. Результаты тестов

После завершения выполнения тестов вы можете просмотреть отчеты Allure, используя следующие команды:

mvn allure:report
mvn allure:serve


Первая команда создаст отчет, а вторая — откроет его в браузере.
